# Earlier graphical prototype (historical reference)

一个精简的 3D 体素破坏实验：**C 应用 + 整数连接图 + raylib + Jolt + GNU Make**。

包含两个场景：

- **木箱爆炸**：296 个体素构成空心箱子；爆炸削弱相邻体素的连接，断开的连通块成为独立刚体，飞散、旋转、落地和堆积。也可以点击箱体做局部爆破。
- **悬臂梁断裂**：144 个体素构成笔直的梁，左端固定；增加末端载荷，按整数重量与杠杆距离估算各截面的需求，超载后断开，剩余部分继续连接，脱落部分成为刚体。

## 构建与运行

需要 64 位 GCC / G++、GNU Make 和 Python 3.11 或更新版本。首次构建会自动下载官方固定提交的源码压缩包，并核对 SHA-256；之后可以离线构建。也兼容相同版本的已有 Git 检出。

```powershell
mingw32-make -j4
mingw32-make run
```

安装的是 `make` 时可直接使用 `make -j4`、`make run`。Windows 已在 GCC 16.2 / MinGW-w64 下验证。工程自身和依赖均由 Makefile 直接编译，无需 CMake。Linux 构建分支也已提供，但本次未在 Linux 上运行验证；需要桌面 OpenGL、X11 开发包。

构建产物为 `build/pixphysiccc.exe`，也可以直接双击运行。无外部模型、纹理、字体或其他运行时资源。

```powershell
mingw32-make test       # 断裂核心与实际 Jolt 物理测试
mingw32-make smoke      # 打开窗口，自动演示两个场景，保存截图与结果后退出
mingw32-make clean      # 仅删除本项目 build 目录，保留已拉取依赖
```

## 操作

| 输入 | 功能 |
|---|---|
| `1` / `2` | 木箱 / 梁 |
| `Space` | 木箱爆炸 / 梁末端载荷增加 25 |
| 鼠标左键点击箱体 | 局部爆破，每次重置后可爆破一次 |
| `+`、`↑` / `-`、`↓` | 梁载荷增加 / 减少 25 |
| `R` | 重置当前场景 |
| `P` | 暂停 / 继续刚体运动 |
| `B` | 显示尚存的连接 |
| `G` | 显示连接需求与损伤的颜色，青色低、红色高 |
| 右键拖动 / 滚轮 | 环绕相机 / 缩放 |
| `Esc` | 退出 |

暂停时仍可操作断裂和载荷，便于查看拆分结果。每次木箱重置后只接受一次爆炸，便于比较相同参数。

## 代码结构

```text
src/main.c       场景、交互、绘制、连通块到刚体的映射
src/voxel.c/h    纯 C 六邻居连接图、整数损伤、BFS 分组、梁的承重近似
src/rigid.cpp/h  小型 C ABI，将复合碰撞形状和运动交给 Jolt
tests/           无窗口的断裂与刚体测试
tools/           固定版本依赖获取、构建辅助、图形冒烟检查
vendor/          自动获取的依赖源码（Git 忽略）
build/           程序、测试、依赖静态库、验证截图（Git 忽略）
```

所有场景和断裂逻辑使用 C11。只有 Jolt 本身与 `rigid.cpp` 使用 C++17。每个连通块对应一个由多个立方体组成的复合刚体；分裂时继承原刚体的质心速度与角速度，不会将全部碎片速度归零。模拟固定步长为 1/120 秒。

## 模型与可调参数

这是游戏用的近似模型，载荷与强度使用游戏单位，未标定成牛顿或帕斯卡。没有弹性弯曲、连续应力场或真实木材本构求解。

- 网格索引、连接强度、损伤与载荷为整数；梁的重量和力臂累计使用 `int64_t`。距离、位置和刚体运动使用浮点数。
- 箱体使用较强的 2×2 表面块内部连接、较弱的块间连接。材料编号区分箱子的六个面；目前没有实现木材纤维各向异性。
- 梁按纵向截面累计自重和末端载荷，再均摊到仍存活的纵向连接。这适用于演示中的规则悬臂梁，不是任意结构的通用应力求解器。部分连接断开后会重新分配载荷，直到稳定或脱落。
- 静载只比较承载需求与剩余强度，不会每帧扣血。爆炸损伤与用于飞散的冲量分别计算。
- Jolt 处理碎片之间和地面的碰撞；当前碰撞不会进一步触发断裂。梁支座的柱子是固定端的视觉标记。

调整体素尺寸和质量：`src/main.c` 中的 `CELL_SIZE`、`CELL_MASS`。调整箱体连接强度：`src/voxel.c` 中的 `add_bond()`；调整爆炸半径、强度和飞散速度：`src/main.c` 中的 `explode()`。
